# Write plain

## Check each sentence

1. **Does it say something specific?** If it could appear in any
   project's docs unchanged, cut it or add the real fact or number.
2. **Is it short?** One idea per sentence. Split long ones.
3. **Is it active?** "The loader parses the file", not "the file is parsed".
4. **Is the word plain?** use, not utilize. help, not facilitate.
   many, not numerous. if, not in the event that.

## Cut on sight

- Hype: pivotal, game-changing, seamless, robust, cutting-edge, unlock.
- AI tells: delve, leverage, crucial, showcase, tapestry, landscape,
  testament, "not just X but Y", "it's worth noting".
- Filler: "in order to" → "to". "due to the fact that" → "because".
- Hedging stacks: "could potentially possibly" → "may".
- Chatbot lines: "I hope this helps", "Great question", "Certainly!".
- Em dashes. Use a period or comma.
- Bold on every other word. Emojis in headings. Title Case Headings.

## Last check

Read it once as the reader. What would they do or know after reading?
If the answer is "nothing", cut more.
