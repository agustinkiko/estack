# Encode lessons in structure

- A rule in prose works only when an agent reads it. A failing check
  works every time.
- When a lesson repeats, make the build catch it: a lint rule, a type, a
  schema constraint, a test, or a script.
- Once the check exists, delete the prose that said the same thing. Keep
  only the reason, if the check cannot show it.
- A lesson that needs judgment and fits no check gets one short note
  where the agent reads it at the right moment, with an example of the
  failure.
